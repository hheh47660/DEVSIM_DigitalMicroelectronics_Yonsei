3. [Step 1] A Simple Simulator with Python OOP

The physics of this step is just three lines (the textbook square-law model):

Cutoff · Linear · Saturation
Vg ≤ Vth :  Id = 0
Vd < Vg−Vth :  Id = k[(Vg−Vth)Vd − Vd²/2]
Vd ≥ Vg−Vth :  Id = (k/2)(Vg−Vth)²

k = µn·Cox·W/L rolled into one gain factor — with transistor width W = 1 µm, so the current comes out in A/µm, the same unit as the Step 2 DEVSIM results. The current() method in the code is exactly these three lines.

Python tools you pick up in this step

numpy — compute whole arrays of numbers at once, no loops
pandas — organize results into tables (DataFrame), save CSV
plotly — one line from a DataFrame to a chart
classes — explained below

What are classes and methods?

A class is a cookie cutter, and each cookie stamped out of it is an instance. The cutter carries two things: values each cookie remembers (attributes — e.g. the threshold voltage) and functions that work with those values (methods — e.g. computing the current). The first argument self means "this very cookie".

class SimpleMosfet:                 # class: the blueprint for one device
    def __init__(self, vth, k):     # constructor: runs when an instance is created
        self.vth = vth              # attribute: a value this instance remembers

    def current(self, vg, vd):      # method: a function inside the class
        ...                         # uses self to reach its own attributes (self.vth, ...)

mosfet = SimpleMosfet(0.6, 2e-4)    # create an instance (cutter → cookie)
mosfet.current(1.0, 2.0)            # call a method

4. [Step 2] A Real TCAD Simulator with DEVSIM

Now drop the Step 1 formula model and attach an engine (DEVSIM) that actually solves the semiconductor physics equations. There are four of them — detailed derivations are covered in class.

Poisson equation
∇·(ε∇ψ) = −q(p − n + ND − NA)

Computes the potential ψ and electric field from the charge distribution. When the gate voltage changes, the channel surface potential and carrier densities change with it.

Electron continuity equation
∇·Jn = q(R − G)

Ensures electron current is conserved inside the device. Includes both electron drift and diffusion.

Hole continuity equation
∇·Jp = −q(R − G)

Conservation of hole current. In an nMOS the electron current dominates, but this is needed for the body and junction analysis.

Quasi-static C–V  [assignment]
Cgg = dQg / dVg

Differentiate the gate charge obtained at each gate voltage. Not in the examples — this is the part you implement.

Where each config.yaml parameter lives in the device

Change these values in config.yaml and the device changes.

How to run

STEP2_RUN.batmosfet.py computes Id–Vg and writes idvg.csv (tens of seconds). Unlike Step 1, notice the subthreshold current (fA–nA) alive in the curve — physics the formula model never had.
STEP2_COMPARE.bat★Key example compare_tcad.py — simulates the devices listed under compare: in config.yaml (default: gate oxide 5/10/20 nm) one by one and overlays them on one chart. Change the settings and the chart changes. Note that the code has the same shape as Step 1's compare.py.

5. [Step 2] How the Code Works

Calls flow down from top to bottom, and results flow back up.

The order one analysis flows through

Why do the paths split? Current (Id) only exists when electrons actually flow, so it needs the electron/hole computation. Capacitance (C–V) only needs the amount of charge stored on the gate at each voltage, so it can be computed more cheaply. — This is why you must not call enable_transport() when you implement the C–V assignment.

How physics equations get into the computer

Curiously, the equations are nowhere in our code. When simulator.py calls the single line CreateSiliconDriftDiffusion(...), the four stages below happen.

The file where these string equations actually live: .conda\Lib\site-packages\devsim\python_packages\simple_physics.py. Feel free to open it if you are curious (not required).

Frequent terms (know these and it all reads easily)

TermMeaning
TCADShort for Technology Computer-Aided Design — the field of simulating semiconductor processes and devices from physical equations.
meshThe fine grid a device is chopped into for computation. An equation is set up at every grid point.
contactA metal terminal that applies voltage to the device (4 of them: gate, source, drain, body).
equilibriumThe state with no voltage applied at all. Every computation starts from here.
sweepRepeating the same computation while stepping a voltage. The result becomes a curve.
Newton iterationGuess an answer → check the error → correct, repeatedly, closing in on the solution. The RelError in the console is that error.
solveThe DEVSIM command "solve the equations under the current conditions". Called again every time a voltage changes.

6. [Step 3] Build a GUI Tool with Streamlit

A simulator you can only drive from code is not yet a tool. In the final step you package it as a GUI that runs in the browser, using Streamlit.

What Streamlit does for you

Streamlit is a library that turns a Python script into a web page — which is why you can build a GUI without any web knowledge.

Description
LaunchDouble-click the bat and Streamlit starts a small web server on your PC and opens the page in your browser. The black console window is that server — close it and the GUI closes too.
Screen elementsOne Python line is one screen element: st.slider() = a slider, st.button() = a button, st.plotly_chart() = a chart. No HTML/CSS needed.
LayoutNo positioning needed either — elements are placed automatically, top to bottom, in the order the code calls them. Use st.columns() only when you want a side-by-side split (mini_app's Device 1/2 is the example).
UpdatesWhenever you touch a slider or button, the whole script re-runs from the top and the screen is redrawn. Play with mini_app while reading its code and this will click.

How to run

STEP3_MINIAPP.bat★Key example mini_app.py — put Device 1 / Device 2 side by side, set Vth·k for each, then press Run simulation to compare the two curves on one chart.
Compare with DEMO.batThe demo is the finished version: the same structure with the Step 2 TCAD engine attached and Id–Vd·C–V added on top. The distance between mini_app and the demo is exactly your final assignment.
